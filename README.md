# English Vocabulary — 5,000-word learning plan

本项目将整理 **5,000 个实用英语词汇**，覆盖日常交流和编程阅读。每个词条采用紧凑表格，包含音标、词性、中文释义/常见用法、英文例句和中文翻译。释义以常用语境为主；例句尽量自然、简短。

## 分类规划

| 分类 | 目标词数 | 内容 |
|---|---:|---|
| 日常基础与交流 | 1,500 | 高频基础词、问候、家庭、饮食、出行、购物、社交、情绪与健康 |
| 通用阅读与表达 | 1,000 | 常见动词、形容词、副词、连接词、短语与表达观点 |
| 编程通用英语 | 1,000 | 文档常见词、代码操作、数据、类型、错误、测试、构建与部署 |
| 软件工程与计算机 | 1,000 | 网络、操作系统、数据库、工具链、协作、性能与安全 |
| Rust / Python / Java 专项 | 500 | 语言特有术语、API 文档表达及常见搭配 |
